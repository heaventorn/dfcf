怎么记账：买、卖、分红、转钱进来

什么时候在哪做会自动写什么
真下单买入 到持仓页把每只的成本价改成实际成交价、份额改成实际股数， 然后回这里点「📌 实验仓位 → 真实成交」 positions.json（去掉实验标记）· 事件日志
按计划买 / 卖 「配置与计划」→ 确认计划 → 点「✓ 确认执行，写入账本」 positions.json · 现金流台账（买入记支出、卖出记收入，各含手续费）· 事件日志
在持仓页手工卖 持仓页卖出之后，回这里手工记一笔「卖出」；有手续费就再记一笔「手续费」 持仓页只改 positions.json + 记一行日志，台账不会自动动 —— 所以钱要你补
分红到账 / 逆回购利息 这里手工记一笔「分红」或「利息」 现金流台账 · 事件日志
从别处加钱进来 这里手工记一笔「入金」，顺手把右上角「总额」改成新的数 现金流台账 · 事件日志
一句话的原则：份额和成本以 positions.json 为准，钱的来去以台账为准。 这两个账本只有同时对上，页面上的「累计盈亏」才是真的 —— 只改其中一个， 数字不会报错，只会慢慢变得不对，那才是最麻烦的。

手工记一笔

金额永远填正数，方向由类型决定：入金 / 分红 / 利息 进钱，出金 / 手续费 出钱。 只有「调整」可以填负数，用来对齐对不上的历史差额。手工记的买入 / 卖出不带手续费， 要算费用就单独记一笔「手续费」。

持仓评估（一个月一次）

桶 / 标的跟踪误差日均成交 溢价结论
只看产品本身，不看组合：① 跟踪误差 = 净值 vs 该桶的指数基准，近 250 个 交易日年化，分红 / 份额折算日和单日异常偏离都剔除；② 日均成交 = 近 20 日成交额，太薄的买不进也卖不出；③ 规模 = 季报口径，低于 2 亿提示、 贴着 5000 万清盘线报要查；④ 溢价 = 场内价相对实时估值，超过该桶的闸门就提示。 费率、基金公告这些要人工核的东西，暂时不进这一层。

日快照

日期累计今日盈亏 风险乘数闸门
收盘后自动记一条（服务开着就行），周末和节假日不记。 同一天重复跑只覆盖同一条。今日盈亏 = 今天这条的市值 − 上一条， 所以当天有入金 / 出金的话它会一起算进去，那种日子看「累计」更准。
