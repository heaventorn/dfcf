# 东方财富 · 当日市场信息爬虫

自动登录东方财富账号，抓取当天 A 股市场信息，并自动生成**「DFCF 本地终端」**：
大盘总览 + 自选与持仓两页满屏面板，左侧一条纯文字任务栏在六个页面之间单击切换，
另有一个内嵌的 3D 地球「全球眼」（`godseye/`，跑在 5180）。

## 功能

- **登录**：Playwright 弹出浏览器窗口，用「东方财富 App」扫码登录，会话 Cookie 本地持久化；登录失效后自动重新引导
- **多源自动切换**（核心特性）：每种数据配置多个数据源，某个来源被风控/限流（断连、空数据、结构异常、风控页）时，自动切换到下一可用来源；异常来源进入冷却期并自动恢复，运行结束打印各来源健康状态
- **采集**（当日实时数据）：
  - 主要指数：上证、深证成指、创业板指、科创50、北证50、沪深300
  - 市场广度：全市场涨跌家数、涨停/跌停家数、高位连板
  - 板块表现：行业板块涨幅榜、概念板块涨幅榜
  - 个股表现：涨幅榜 Top10
- **分红记录取数**：天天基金 F10 分红送配（`sources.get_dividends`）；原先基于它的红利 ETF「股息率分位 / 买卖点」分析模块已随旧报告链路移除
- **罗力豪空中飞人指数**（主页右下方窗口）：泡沫爆破风险指数（0-100，越高越危险），五维评分（估值 20% / 盈利证伪 15% / 杠杆 15% / 流动性利率 25% / 政治宏观 25%），全部指标自动抓取打分
- **主页·大盘总览**（`output/index.html`）：顶部一排指标卡（6 大指数 + 涨跌家数 + 涨停跌停），下面是满屏面板 —— 上证分时、涨跌分布、涨停梯队、行业板块、概念板块、上证日K（MA5/10/50）、个股涨跌幅榜、财经快讯（两栏）。**纯静态 HTML，没有 3D、没有图表库**，打开就是数据，双击也能看
- **自选与持仓**（`output/portfolio.html`）：我的持仓 / 资产配置桶（目标 vs 实际）/ 我的自选 / 组合概览 / 持仓分布 / 风险与再平衡检查，一页看全
- **左侧任务栏**：大盘总览 / 自选与持仓 / 个股详情 / 资产配置桶 / 策略执行台 / **全球眼**，六个入口同窗口单击切换
- **实时新闻推送**（`live_server.py`）：脚本启动后自动在后台拉起，**每 5 分钟**重抓一次全球新闻（东财 7x24 / 华尔街见闻 / 财联社 / 金十 / 同花顺 / 新浪 7x24）；主页按版本号轮询 `/api/news`，有新内容就**就地刷新财经快讯那一栏**（不整页重载）；关掉启动脚本窗口时服务随之退出
- **新闻可跳原文**：快讯栏里每条标题都是链接（新窗口打开原站），信源在抓取时保留了原文地址
- **我的自选**（主页右上方窗口）：自己维护的标的清单，分 **ETF / 股票 / 其他** 三组（存 `data/watchlist.json`）。**只跟行情——不记成本、不算盈亏**（那是「我的持仓」的事）。在持仓管理页 `http://127.0.0.1:8765` 的「📌 自选管理」标签填个代码就能加入；场内 ETF/股票取实时价，场外基金取净值（带净值日），国债逆回购显示的是年化利率
- **个股终端**（`stock.py` + `stock.html`）：主页里点持仓/自选任意一行 → **同一个窗口**进入个股页（详细报价 / 五档盘口 / 分时含均价 / 日K / 月K / 均线·BOLL 指标切换 / 量能 / MACD），返回键或 Esc 回主页。后台按 **3.5s / 60s / 300s** 分档刷新，**同一只票合并请求**（多开标签页也只打一次上游），**收盘、午休、周末自动停刷**，页面关掉 60 秒后连后台也不再为它抓数
- **隐私文件加密**（`secure_store.py`）：持仓、自选、策略蓝图、Cookie、API Key 和 output/ 里的台账·日志·追踪，落盘一律是密文（`文件名.enc`）；密钥由「你输入的密码 + 本机密钥文件 `data/pwd.key`」经 Argon2id 派生，源码里不留可离线爆破的哈希。换密码不用重加密文件

## 全球眼（内嵌的 3D 地球，5180）

`godseye/` 里内嵌了开源项目 **God's Eye View**（MIT，bilawalsidhu/gods-eye-view）：一个可以自由飞行、叠加飞机/船舶/卫星/地震/摄像头/天气等实时图层的 3D 地球。它是**原样搬进来的真代码**，不是重画的仿制版。

- **双端口并行**：DFCF 自己的大盘总览/自选持仓/个股在 `8766`，3D 地球在 `5180`，两个服务互不阻塞。`main.py` 启动时会一起把它们拉起来（关掉启动脚本窗口，两个一起退出）。
- **同窗口跳转**：两边用的是**同一条左侧任务栏**，点「大盘总览」或「全球眼」就在同一个窗口里换页。按住 Ctrl / 中键点，则按浏览器习惯开新标签。
- **干净版**：相机上的圆形遮罩、角落的 TOP SECRET/REC/MGRS 特效文字、`GOD'S EYE VIEW` 品牌标题、`ACTIVE STYLE` 指示、录制安全框全部关掉（见 `godseye/public/dfcf-shell.css`），只留地球与各层面板。
- **快**：`main.py` 启动时先 `vite build`（约 6 秒），然后用 `vite preview` 托管 `dist/` 静态文件，而不是跑 `vite dev`。开发服务器一页要发 800 多个模块请求 / 40 多 MB，构建后是 170 多个请求 / 不到 10 MB，冷启动从十几秒降到两秒左右。
- **不需要任何付费 Key**：语音（OpenAI Realtime）、Google 实景 3D 瓦片、Google 地点/街景这些**需要花钱的接口代码已经从本仓库里删掉了**。剩下能用的图层全部是免费公开数据源（飞机、船舶、卫星、地震、山火、网络摄像头、无线电、天气等），不配任何 Key 也能跑。
- **前置依赖**：Node.js 24+（`godseye/` 是 Vite + CesiumJS 项目）。首次使用需要在 `godseye/` 目录里执行一次 `npm install`；没装 Node 或没装依赖时，DFCF 其它功能照常，只是任务栏里的「全球眼」打不开。

## 使用

```bash
# 1. 完整流程（自动登录 + 采集 + 生成 HTML 报告）
python main.py

# 2. 仅登录（保存会话，之后可跳过重复扫码）
python main.py --login-only

# 3. 跳过登录，直接用公开接口采集（行情数据本就无需登录）
python main.py --no-login

# 4. 查看历史快照趋势 / 环比（需先采集过至少两轮）
python history.py
python history.py --days 30 --field breadth_up   # 某指标时间序列
```

首次运行 `python main.py` 会弹出浏览器窗口，用「东方财富 App」扫一扫登录页面左侧二维码即可。
登录成功后 Cookie 保存到 `data/cookies.json`，下次运行自动复用，无需重复扫码。

> 直接跑 `python main.py` 也会**先要一次访问密码**（隐私文件是密文，没有密钥读不出来）。
> 密码就在你启动它的那个 CMD 窗口里输 —— 每敲一个键回一个 `*`，输完回车即可。
> 平时更推荐双击 `启动爬虫.bat`：它的第一步就是解锁保险库，然后才拉起 `main.py`。
> 详见下面「隐私文件加密」一节。

## 数据目录：`data/` 与 `output/`

两类东西分开放，**整条界线就是「丢了能不能重算」**：

| 目录 | 放什么 | 入库吗 | 丢了怎么办 |
| --- | --- | --- | --- |
| `data/` | **你手动维护的数据 + 凭据**：`positions.json`（持仓）、`watchlist.json`（自选）、`strategy.json`（策略蓝图）、`cookies.json`、`secrets.json`，以及钥匙 `pwd.key` / `keyring.json` | **不入库**（`.gitignore` 排除整个目录） | 找不回来，必须自己留着 |
| `output/` | 程序生成的缓存与报告：主页、历史库、各类行情缓存、追踪账本 | 不入库 | 删掉重跑即可 |

- 路径常量集中在 `config.py`（`POS_FILE` / `WATCH_FILE` / `STRATEGY_FILE` / `COOKIE_FILE` / `PWD_KEY_FILE` / `SECRETS_FILE`），
  别在别的模块里拼路径。
- **首次运行会自动做两件事**：① 项目根目录若有旧版留下的同名文件，搬进 `data/`；② `data/` 里缺
  `positions.json` / `watchlist.json` / `strategy.json` 时，按 `data_templates/*.example.json` 生成。
  所以新机器克隆下来直接 `python main.py` 就能跑，不用手工建文件。
- `data/` 里的文件**不会**通过主页的本地服务暴露出去（`live_server.py` 对 `/data/` 一律回 403）。
- **落盘形态是密文**：`data/` 下所有 `*.json`（钥匙文件除外）和 `output/` 里的台账·日志·
  追踪·体检，落盘都是 `文件名.enc`；明文只在内存里。细节见下一节。

## 隐私文件加密（本地保险库）

目的很直白：**就算别人把整个项目文件夹拷走，也看不到你的持仓和账号**。

```
密码 + data/pwd.key  --Argon2id-->  KEK  --解开 data/keyring.json-->  数据密钥 DEK
DEK + 每个文件独立随机 nonce  --AES-256-GCM-->  文件密文（原名 + .enc）
```

- **两个因素**：`data/pwd.key` 是随机生成的本机密钥文件，**不放在源码里**；只有「它 + 你记得的密码」合起来才能解出数据密钥。所以源码可以随便公开，光有代码推不出密钥
- **抗爆破**：Argon2id 参数 `m=64MB, t=3, p=4`（旧版是 16MB / 2 轮）；想硬猜密码，每试一次都要付 64MB 内存 + 3 轮的开销
- **性能无感**：慢哈希只在**启动解锁时算一次**（约 0.05 秒），之后每个文件都是纯 AES-GCM，读约 0.1 毫秒、写约 1 毫秒
- **换密码很轻**：只重新包一次数据密钥，几百个密文文件一个都不用动
- **防篡改**：每个文件独立 nonce，并把文件路径绑进 AAD —— 文件被对调或改过会直接解密失败，不会悄悄给你一份错数据
- **钥匙只在这一台机器这一段进程里**：数据密钥只在内存和子进程环境变量里，程序退出就没了

### 怎么用

日常完全不用管，正常启动即可：

```bash
启动爬虫.bat            # Windows 双击：先在 CMD 窗口里输密码解锁，再跑采集
python auth_check.py   # 跨平台等价写法
```

第一次会请你**设一个访问密码**（至少 6 位，建议 12 位以上或一句好记的长口令），并自动把现存明文全部加密。
之后的每次启动输这个密码即可（就在当前 CMD 窗口里敲，跟填命令行一样）；`data/pwd.key` 和密码**两样都要留好**。

> 输密码时每敲一个键会回一个 `*`，看得见才算数。问你密码之前，程序会**自动把输入法切成英文键盘**
> （中文输入法开着的时候，字母会被它吃进候选框，程序一个字符都收不到），答完再切回你原来那个，
> 所以不用手动按 `Shift`。
> 万一还是敲不进（比如键盘焦点被别的窗口抢走），等 25 秒它会自己改用弹窗让你输，不会把你堵在门口。

要单独操作保险库（改密码 / 备份 / 看状态 / 手动改某个加密文件）就双击 **`加密工具.bat`**，
它会给出一个数字菜单：

```
python secure_store.py status               # 看哪些文件已加密
python secure_store.py rekey                # 换密码（不重加密文件）
python secure_store.py backup D:\备份\dfcf-vault.json   # 导出备份（强烈建议做一次）
python secure_store.py restore D:\备份\dfcf-vault.json  # 换机器 / 丢了 pwd.key 时恢复
python secure_store.py edit strategy.json   # 用记事本改加密文件，存回自动加密
```

### 一定别忘的两件事

1. **做一次备份**：`python secure_store.py backup <路径>` 会把钥匙串和 `pwd.key` 打成一个文件。
   它等于一把备用钥匙，请放到**离线位置**（U 盘 / 密码管理器）。`data/pwd.key` 丢了，
   光有密码也解不开数据，只能靠这份备份救回来。
2. **别把整个项目目录同步到网盘 / 公开仓库**：`output/index.html`、`latest_market.json`、
   `history.db` 为了让浏览器和 SQLite 直接读，**不在加密范围**，内容里却含你的持仓；
   它们每次运行都会重建，不需要备份。

## 罗力豪空中飞人指数

泡沫爆破 / 经济危机风险指数，**0-100 分，越高越危险**。评分标准**固定**，全部指标由公开数据自动采集、按固定阈值打分，**无需人工填分**。

- **分级**：0-25 安全区 | 26-50 警戒区 | 51-75 高危区 | 76-100 爆破临界区
- **五维权重（固定）**：估值·市场过热 20% / 盈利·成本挤压 15% / 杠杆·财政债务 15% / 流动性·利率 25% / 政治·宏观 25%
- **15 个计分子项（全部自动）**：
  - 估值：标普500距52周高点、纳指距52周高点、VIX 自满度
  - 盈利/成本：核心CPI同比、原油价格
  - 杠杆/财政：美国债务/GDP、债务总额同比、联邦基金利率
  - 流动性/利率：10Y美债、2Y美债、USD/JPY、收益率曲线(10Y-2Y)
  - 政治/宏观：政策不确定性指数、美元广义指数、30Y美债
- **参考指标（不计分，独立展示）**：恐慌指数 VIX、黄金价格（含注释）
- **数据源**：FRED（美债/通胀/VIX/美元/债务/政策不确定性等）、腾讯（黄金/原油）、新浪（USD/JPY）
- 阈值规则定义在 `airman.py` 的 `_rule_*` 函数中（固定标准，如需调整改代码即可）
- 每次运行实时抓取并打分，输出总分 + 五维得分条 + 已计分信号清单 + 参考指标，渲染在主页右下方窗口

### 现在留着的三个方案

下拉框里的类别是给人看的标签，写在 `strategy.json` 每个策略的 `cat` 字段里；
不写就按 `risk` 自动分「稳健 / 均衡 / 进取」三档。它不参与任何计算。

| 类别 | id | 名称 | 风险腿 | 年化 | 最大回撤 | 波动 | 夏普 | 最差单年 | 最差滚动3年 | 最长回本 |
|---|---|---|---|---|---|---|---|---|---|---|
| 稳健 | A2 | 保守 E20 | 20% | 5.47% | **-3.76%** | 2.42% | 2.26 | +0.90% | +2.33% | 1.2 年 |
| 均衡 | Z0 | R2 实盘版 | 33% | 7.87% | -8.34% | 5.05% | 1.56 | -3.59% | +1.39% | 1.7 年 |
| 进取 | A5 | 进取 E35 | 35% | 6.73% | -8.29% | 3.88% | 1.74 | -2.78% | +0.82% | 1.8 年 |

样本 2006-01-04 ~ 2026-09-21（含 2008 全球金融危机），半年再平衡，**未扣费率**。
下拉框按 `risk` 排序：A2（0.20）→ **Z0**（0.33）→ A5（0.35）。

**Z0 是 2026-09 定稿的「R2 实盘版」**，和上一版的区别就三件事：

* **债券只买两档久期**，各 22%：1-3 年（`511030` / `511220`）+ 7-10 年（`511520` / `511270`）。
  回测代理也换成了对应的中证 1-3 年（H11002）和 7-10 年（H11004）综合债指数 ——
  旧版的代理是中证全债 H11001（久期 4-5 年），**低估了自己实际承担的久期风险**。
* **纳指 100 不买**（那 13% 给红利腿）：定稿时场内溢价 14%，是历史最高档。
  A股红利 10% → 15%、港股红利 12% → 16%，红利合计 31%。
* **风险腿 37% → 33%**，现金 8%、黄金 15%、A股宽基 2%。

代价写在表里：Z0 的波动（5.05%）比 A5（3.88%）高、回撤比 A5 略深，
换回来的是每年多约 1.1 个百分点。**13% 的回撤上限在久期拉长之后更吃紧**，
见 `部署说明.md` §8.5 的压力测试。

上面那组权重是**蓝图**。真下单时还要过三层风控（趋势闸 / 空中飞人 / 指数回撤）——
比如 2026-09-19 那天三层全触发，风险腿只按蓝图的 28% 买（红利 + 宽基合计
9.2%，减下来的全进现金），所以「今天该买什么、买多少」以页面上的**买卖计划**为准，
而不是拿 100 万直接乘上面这张表。
表里的年化和回撤是 **v3.3.0 起「风险预算三层全开着」**的口径（`gate: true`）；
扣 0.45%/年费率之后的版本、以及页面上的费用下拉框，见 `部署说明.md` §8.5。

### 盈亏追踪：回测算「如果」，它算「实际」

回测回答的是「历史上这么做会长什么样」；盈亏追踪回答的是「我们从某天起真的这么做，
到现在长什么样」。这两个数字**应该**不一样 —— 差在哪、差多少，才是有效信息。

建账那天（2026-09-19）把 100 万的计划份额记进 `output/track.json`，之后：

* 打开策略台的「盈亏追踪」页签就自动记一条当天快照（同一天只留一条）；
* 91 天 / 半年 / 一年 / 两年四个里程碑，到点那天按**复权净值**自动重算累计和年化；
* 旁边并排显示**同一策略、同一时间段、扣 0.45%/年**的回测年化，差多少一眼看见。

命令行等价用法（本机 Python 3 就是 `py`）：

```
py tracker.py init           # 按当前买卖计划建账，今天就是起点
py tracker.py                # 打报告，顺手记一条今天的快照
py tracker.py report --json  # 给页面 / 别的脚本用
py tracker.py init --force   # 推倒重来，旧的存成 output/track.bak.json
```

三个口径上的讲究：

* **净值一律用东财复权净值**（含分红再投），不是单位净值 —— 511520 这类债券 ETF
  两者差过两百个百分点，用单位净值会算出「白干」。取不到复权净值时才退回场内价，
  报告里会标出来。
* **现金默认按 511360 短融 ETF 计息**（比活期多约 0.6%/年）。就想放活期的话，
  把 `output/track.json` 里的 `cash.vehicle` 改成 `null`。
* 还没真买时是**纸上建仓**口径；真买了之后在策略台点「确认执行」写进
  `positions.json`，报告会自动切成**实盘口径**（份额 × 现价，分红现金要自己加回来）。
  中途改了份额，直接改 `output/track.json` 的 `legs` 就行，不用重算起点。

### 风险预算：三层闸门相乘 + 一个地板（v3.3.0）

`strategy.json` 的 `gate` 段是全局配置，某个方案用不用看它自己的 `gate` 字段；
**现在 A2 / Z0 / A5 都是 `true`**，三层都会参与计算（`risk_overlay`）：

| 层 | 看什么 | 乘数 |
|---|---|---|
| ① 趋势闸 | 中证沪深300**全收益**（H00300）vs 200 日均线，只在再平衡当天判 | 跌破 ×0.5 |
| ② 空中飞人指数 | 泡沫爆破风险评分 ≥76 / ≥51 / ≥26 | ×0.5 / ×0.7 / ×0.9 |
| ③ 指数回撤 | H00300 近 252 日回撤 ≤-15% / ≤-12% / ≤-8% / ≤-6% | ×0.4 / ×0.6 / ×0.8 / ×0.9 |

三层**相乘**，再套地板 `min_keep = 0.30`（风险腿最少留三成），减下来的份额记到货币桶；
黄金不在风险桶里，不参与打折。

**频率是刻意不对称的**：减仓随时执行，加仓只在 1/7 月的再平衡窗口执行，最小步长 5%。
实测放开「随时加仓」会让最大回撤从 -5.95% 掉到 -21.68%、操作次数从 67 涨到 239 —— 别改。

> 早期版本的「只切趋势闸开关」对照表（6.49% / -10.44% 那一组）已经不适用了：
> 那是在风险预算和溢价纪律落地之前的口径，现在三套方案都开着闸，数字按上表算。

### 为什么先做这个，而不是先做策略

策略会换（今年觉得 E25 好，明年可能想加黄金），但**下单的手**不需要跟着换。
所以先把执行机制做出来，策略只是它的一个输入：以后想加一套新玩法，
往 `strategy.json` 里写一组权重就行，回测和盯盘同时生效，不用改代码。

### 两个文件的分工

| 文件 | 是什么 | 谁改 |
|---|---|---|
| `positions.json` | **账本** —— 我实际上买了什么（代码 / 成本 / 数量 / bucket） | 你，或在持仓页改 |
| `strategy.json` | **蓝图** —— 我应该持有什么（目标权重 / 再平衡规则） | 你改 json，系统自动重读 |

系统做的事只有一件：**算这两个文件的差额**，然后翻译成买卖。

### 怎么用

1. 右上角填「可投资总额」——保险和半年生活费**不要**算进来。
2. 在持仓页录入实际持仓，给每笔填 `bucket`（`cash` / `bond` / `divA` /
   `divHK` / `broad` / `gold` / `ndx`）。没填的会显示在「未分类」里，
   不参与配置计算，页面会提醒你。
3. 打开策略页 → 看「配置对照」：哪个桶漂移超过 5% 会标黄。
4. 看「买卖计划」→ 点「确认执行」写入账本。**没有券商 API，不会自动下单**，
   这一下只是把你的决定记下来。

### 加一套新策略

只改 `strategy.json`：

```json
"C1": {
  "name": "我的新方案",
  "risk": 0.22,
  "gate": false,
  "weights": { "cash": 0.42, "bond": 0.31, "divA": 0.08,
               "divHK": 0.045, "broad": 0.035, "gold": 0.05, "ndx": 0.06 }
}
```

权重会自动归一化，`gate: true` 表示启用趋势闸（沪深300 跌破 200 日均线时，
风险资产目标权重砍半转货币）。保存后刷新页面即可，回测数字会立刻跟着变。

### 接入大模型

Key 二选一：

```powershell
# 方式一：环境变量
$env:DEEPSEEK_API_KEY = "sk-..."
# 方式二：建 data/secrets.json（data/ 整目录不入库）
# {"deepseek_api_key": "sk-..."}
```

然后重开服务，在「模型分析」页点发送。模型拿到的是真实持仓 + 目标权重 +
回测数字，**不联网、不看新闻**。

模型名以 `strategy.json` 的 `llm.model` 为准。`GET /models` 实际返回两个：

| 模型 | 说明 | 实测 |
|---|---|---|
| `deepseek-flash` | 默认。先思考再作答的两段式模型 | 7-21 秒 |
| `deepseek-v4-pro` | 更慢更贵一档 | ~5 秒起 |

页面下拉框可以直接切。名字写错时接口会原样报出支持的名单，然后自动试下一个，
不会闷在那里让你猜。

**注意 token 预算**：`deepseek-flash` 会先输出一段 `reasoning_content`（思考），
再输出正文。`max_tokens` 卡得小（比如 1600）会出现「思考写完了、正文没位置」
——返回的正文是空的。所以 `llm.max_tokens` 默认给了 8000，页面下方还能点开
看模型的思考过程（判断它有没有在胡扯，看思考比看结论更有用）。

### 刻意不做的事

* **不自动交易**。出 bug 最多是算错一笔建议，不会把账户打错。
* **不让模型产生买卖信号**。决策来自权重和账本，模型只负责把数字读成人话、
  指出你可能忽略的风险。否则你没法解释「为什么它昨天看好今天变卦」。
* **回测和实盘用同一个 `strategy.json`**。纸上跑的是 A、手上做的是 B，
  这种漂移一旦发生就再也说不清业绩该归谁。

### 数字该怎么读（重要）

回测样本 2006-01-04 起，正好在 2006-07 那轮大牛市之前，**起点本身带顺风**；
中证红利低波指数 2017 年才发布，2017 年前是按规则回填的，存在幸存者偏差；
港股红利 2014-11 之前没有全收益指数，是用价格指数 + 7.09% 年化股息补的，
且没有逐笔扣 20% 股息税；回测不含 ETF 费率，页面上可以选扣 0.45% / 0.80% 试算。

**往后看，稳健档（A2）这类按 4.5-5.5% 年化、进取档（A5）这类按 6-7% 预期，
再减 0.4-0.5% 费率；均衡档（Z0 R2 实盘版）历史 7.36%（已扣 0.45%），但它是最
吃「债券收益率一路下行」的一个组合（而且现在债券腿的久期比旧版长），
按 6-6.5% 规划更稳。**
页面里那张回测表是「历史上长这样」，不是「未来会这样」。

**三层容错**（由内到外）：
1. **连接级重试**：断连 / 超时 / 5xx / 429 自动退避重试（`config.HTTP_RETRIES`）；
2. **来源切换**：硬异常（断连 / 非 200 / 风控页）指数退避冷却并切源；软异常（空数据 /
   校验不过）只切源、不冷却；
3. **整体重试**：所有来源都失败时按 `config.COLLECT_RETRIES` 整链重试。

**风控判定分档**：中文强特征（“访问过于频繁”等）任何响应都判；英文宽泛词
（verify / captcha ...）只在 HTML 响应或 JSON 解析失败时判 —— 避免正常数据正文里
出现这类词被误杀成风控页。

**代码缺陷可见**：非数据源异常（KeyError / AttributeError 等）不再被静默当作
「来源故障」吞掉，而是打印 traceback、计入运行结束的健康报告，且不计入来源冷却。

**代理支持**：读取 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY`（可在 `config.USE_ENV_PROXY`
关掉强制直连）。

**冷却恢复**：硬异常来源按连续失败次数指数退避（15s→30s→60s…，上限 10 分钟），
冷却结束后自动恢复探测，无需人工干预。

## 常见问题

- **部分数据为空 / 接口超时**：程序已内置多源自动切换——东财 push2 被限流时自动改用
  push2delay 延迟镜像 / 腾讯 / 新浪；若多个数据源均异常才可能为空，稍等 15~30 分钟重跑即可。
- **登录后 Cookie 失效**：Cookie 有时效，失效时删除 `data/cookies.json` 后重新执行 `python main.py` 即可重新扫码。
- **浏览器未弹出**：确认已执行 `python -m playwright install chromium`（建议用国内镜像）。
- **新闻没在动 / 看不到自动刷新**：确认 8766 端口上跑的是 `live_server.py`。
  浏览器访问 http://127.0.0.1:8766/api/health 应返回 JSON；
  若 404 说明有别的程序占着端口，关掉旧窗口重跑启动脚本即可。
- **主页点持仓行没反应 / 个股页打不开**：主页是生成产物，改动代码后要重跑一次
  `启动爬虫.bat`；个股页需要 8766 服务在跑（`/api/stock`）。
- **个股页某块显示「—」**：那一块数据源降级了，看 `/api/stock/health` 的 `errors`
  与 `/api/health`；逆回购 / 场外基金本身没有分时与 K 线，主页里也不给入口。
- **忘了访问密码 / 丢了 `data/pwd.key`**：只能靠备份恢复
  （`python secure_store.py restore <备份文件>`）。两样都没有就解不开了 ——
  所以建完保险库**先做一次备份**，见「隐私文件加密」一节。
- **保险库提示找不到 `keyring.json`，但磁盘上有 `*.enc`**：**别选「新建保险库」**
  （会生成新钥匙、老数据永久锁死，工具本身也会拦住），正确做法是从备份 `restore`。
